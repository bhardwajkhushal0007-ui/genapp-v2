# GenApp Version 2: Enterprise Forensic DVI & Kinship Engine

## Directory Structure
genapp-v2/
├── requirements.txt
├── main.py
└── static/
    └── index.html

## Quick Start (Local Run)
1. Install dependencies:
   pip install -r requirements.txt

2. Run server:
   uvicorn main:app --reload

3. Open browser:
   http://127.0.0.1:8000
